# Workforce Analytics & Insights

## Overview

Workforce Analytics & Insights is a Python-based data analytics project focused on exploring employee and workforce data.

The project uses Python, Pandas, NumPy and Matplotlib to answer practical HR and business questions related to employee performance, salary, satisfaction, absence and turnover.

## Current Objectives

- Explore and understand workforce data
- Perform data filtering and aggregation
- Analyze employee performance
- Compare departments
- Analyze salaries
- Investigate employee satisfaction
- Analyze employee turnover
- Create meaningful business insights
- Build data visualizations

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Current Analysis

The project currently includes:

- Dataset exploration
- Data type inspection
- Missing-value checks
- Department analysis
- Average salary analysis
- Performance analysis
- High-performer analysis
- Salary ranking
- Highest-paid employee by department
- Employee turnover analysis
